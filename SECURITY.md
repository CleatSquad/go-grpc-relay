# Security Policy

## Supported Versions

Security fixes are applied to the latest stable release.

| Version | Supported |
| ------- | --------- |
| 0.x     | Yes       |

## Reporting a Vulnerability

Please do **not** open a public issue for a security vulnerability.

Report it privately through
[GitHub Security Advisories](https://github.com/CleatSquad/go-grpc-relay/security/advisories/new),
or by email to <mimou78@gmail.com>.

Include a description of the issue, the affected version, and a reproduction
case if you have one. You can expect an acknowledgement within a few days, and
an assessment of the report shortly after.
